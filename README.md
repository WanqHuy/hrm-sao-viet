# Hệ Thống Quản Lý Nhân Sự & Chấm Công Khuôn Mặt AI - Sao Việt Software

Đề tài RESTful Web Service xây dựng hệ thống quản trị nhân sự, chấm công khuôn mặt ứng dụng Client-side Face AI (Face-api.js), duyệt đơn nghỉ phép và tính lương tự động cho Công ty TNHH Phần mềm Sao Việt (~100 nhân sự).

## Công Nghệ Sử Dụng
- **Backend:** Node.js, Express.js, MongoDB (Mongoose), JWT, Bcryptjs.
- **Frontend / Client AI:** HTML5, Tailwind CSS, Face-api.js (TinyFaceDetector, 68 Landmarks, FaceRecognitionNet).
- **Xuất báo cáo & Mail:** ExcelJS, Nodemailer.
